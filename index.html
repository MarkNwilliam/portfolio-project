Interwell Connectivity

Tracer allocation between injectors and producers, scored with the Allocation Rank Index against the Hirasawa rank method, with tracer mass balance, unrecovered-slug loss reporting and connectivity-aware infill scoring. Independent campaign misfit and suite checks catch a scrambled connectivity matrix rather than flattering it. Standard library Python, unit tested, with a matching interactive dashboard.

Tracer Breakthrough Curve

One-dimensional advection-dispersion breakthrough curve fitting that estimates retardation, dispersivity, delay volume and detection time, with residual-bootstrap confidence intervals on the parameters. Built for sampling design, where knowing when a tracer arrives governs the sampling schedule. Timing comes from step-response crossings rather than a fitted first arrival, because first arrival is not identifiable with a dispersion coefficient. Standard library Python, unit tested, with a matching interactive dashboard.

Live dashboard · Source

Tracer Connectivity ML

Machine learning on tracer allocation data, reported under both random and leave-one-injector-out validation. A well pair is not an independent observation, so a random split puts the same wells on both sides and overstates performance. The dashboard ports CPython's MT19937 so its results match the Python library to nine decimal places, and a pure-noise control feature is included so the feature ranking can be trusted. Standard library only, no dependencies.
